# 日历日期属性

当前内置2026年中国大陆统一放假调休安排。假期块包含周末与调休日，不把整个假期块都称为“法定节假日”。节气按北京时间（UTC+8）日期显示，与是否放假独立，重叠时同时保留。尚未收录年份只显示周末并提示资料未收录，不推断普通工作日、假期或节气。不涵盖地区性与部分公民假期。

来源：国务院办公厅《关于2026年部分节假日安排的通知》，国办发明电〔2025〕7号（2025-11-04）；香港天文台《2026年公历与农历日期对照表》。

节气原表：https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf

假期：1/1–1/3、2/15–2/23、4/4–4/6、5/1–5/5、6/19–6/21、9/25–9/27、10/1–10/7。补班：1/4、2/14、2/28、5/9、9/20、10/10。

热力按当前月、当前收入/支出类型的每日已记金额相对于月内最大日金额绘制，不暗示日期属性导致消费。隐藏金额同时隐藏颜色强度。点击日期可查看金额及占当前月同类型总额的比例。无记录日明确为暂无记录。

## v2.7.0 联网更新

入口为“我的 → 日期资料更新”及日历底部。默认不自动联网。用户开启后，应用启动或返回前台时，按设备当前时间检查今年和下一年；每年24小时内最多一次自动尝试，手动检查不受此时间限制。应用关闭时不保证后台执行。

假期来源：https://github.com/NateScarlet/holiday-cn ，通过其raw年度JSON获取（第三方整理，非国务院官方API）。必须校验年份、日期合法性、重复日期、布尔类型及gov.cn公告引用。来源404只表示该来源没有可用资料，不推断官方是否已经公布。

节气来源：https://www.hko.gov.hk/tc/gts/time/calendar/text/files/T2027c.txt （年份动态替换），必须收齐当年24种不同节气；传统字转换为简体显示。假期与节气更新独立，资料可部分成功。

每个请求最多15秒，响应最多256KB；禁止自动跳转。失败保留已有缓存，不回退为“普通工作日”。缓存及自动检查偏好单独保存在calendar_state，和app_state账单数据隔离。保存失败显示仅当前运行可用。

测试资料：test/fixtures/calendar 内为公开日期事实的源格式样例，分别来自2026.json和T2027c.txt，仅用于离线回归测试；不随应用作为2027假期数据打包。
