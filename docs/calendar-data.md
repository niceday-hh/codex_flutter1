# 日历日期属性

当前内置2026年中国大陆统一放假调休安排。假期块包含周末与调休日，不把整个假期块都称为“法定节假日”。节气按北京时间（UTC+8）日期显示，与是否放假独立，重叠时同时保留。尚未收录年份只显示周末并提示资料未收录，不推断普通工作日、假期或节气。不涵盖地区性与部分公民假期。

来源：国务院办公厅《关于2026年部分节假日安排的通知》，国办发明电〔2025〕7号（2025-11-04）；香港天文台《2026年公历与农历日期对照表》。

节气原表：https://www.hko.gov.hk/tc/gts/time/calendar/pdf/files/2026.pdf

假期：1/1–1/3、2/15–2/23、4/4–4/6、5/1–5/5、6/19–6/21、9/25–9/27、10/1–10/7。补班：1/4、2/14、2/28、5/9、9/20、10/10。

热力按当前月、当前收入/支出类型的每日已记金额相对于月内最大日金额绘制，不暗示日期属性导致消费。隐藏金额同时隐藏颜色强度。点击日期可查看金额及占当前月同类型总额的比例。无记录日明确为暂无记录。
