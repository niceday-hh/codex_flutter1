# 消费洞察方法 · v2.5.0

分析在设备本地完成，支出与收入分开；不调用模型服务、不上传账单。未结束时段截到今天，忽略未来时间、非正数和非有限金额。日期以当地年月日转换为 UTC 日期做天数运算，以避免夏令时天数误差。无记录不能证明零消费；记录天数不是完整度或置信度评分。

## 分析口径

| 维度 | 计算方法 | 限制 |
|---|---|---|
| 等长对比 | 已观察 N 天与紧邻本期开始前 N 天对比 | 不是自然月环比或同比；显示实际日期。对照无记录不计算增长率 |
| 分类变化 | 各分类本期减对照，按差额绝对值排序 | 是算术贡献，不是因果归因 |
| 频次与均额 | Δ笔数×两期均额平均值 + Δ均额×两期笔数平均值 = Δ总额 | 单笔金额不等于商品单价 |
| 周末节奏 | 周末、工作日金额分别除以对应日历天数 | 至少 2 个周末日、5 个工作日和 7 笔；不调整节假日，不检验显著性 |
| 集中度 | 前三类占比、H=Σ占比²、等效分类数=1/H | 仅描述分布；分类口径影响结果，不强套 80/20 或健康评级 |
| 高额线索 | 前 90 天同分类基线；修正 Z=0.6745×(金额−中位数)/MAD，高于 3.5 标记 | 至少 8 笔为产品门槛，MAD=0 跳过；消费偏态使其只适合探索，不代表错误或不合理 |
| 周期线索 | 180 天内同分类、规范化备注、至少 3 次不同日期，周/月间隔和金额容差 | 周间隔中位数6–8天、每间隔偏离≤1天；月26–33天、偏离≤3天；金额偏离中位数≤10%。均为启发式，无法认定订阅 |
| 预算情景 | 当前整月：已记金额/已过天数×月天数；滑块只减少剩余天数最大分类的预计支出 | ≥7天、≥4记账日；假设记录完整及日均稳定，不是置信区间，不回减已发生支出 |

## 依据与项目参考

- NIST Engineering Statistics Handbook, Detection of Outliers：提供 MAD 修正 Z 方法和 3.5 探索阈值，同时强调分布假设及误标风险。这里只筛查高额候选，不做异常值正式检验、不删除记录。
  https://www.itl.nist.gov/div898/handbook/eda/section3/eda35h.htm
- Actual Budget Reports Dashboard：借鉴按日期范围分析、消费对比和多维入口的产品组织。独立实现，没有复制代码或使用其商标素材。
  https://actualbudget.org/docs/reports/
- Actual Budget Schedules：借鉴周期交易作为独立观察维度；自动线索检测规则由本项目定义，不声称该项目采用相同算法。
  https://actualbudget.org/docs/schedules/

没有足够交易语义支持的“必要/非必要消费”“冲动指数”不自动推断；没有资产、负债和完整收入数据，不输出财富、信用或财务健康评分。方法说明、样本限制和关联记录可在每张洞察中查看。
