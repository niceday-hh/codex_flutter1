## 拾光账本 v2.2.0 · 轻量编辑与流畅度升级

### 账单编辑
- 点击账单金额时，不再打开普通输入框，改为账单附近弹出的 iOS 风轻量金额编辑卡，并提供内置数字键盘。
- 点击分类时打开半屏分类 Sheet，新增分类搜索和“最近使用”分类，减少重复翻找。
- 点击名称 / 备注时，会显示当前分类下最近使用过的备注，可一键复用后继续编辑。
- 长按账单仍保留完整管理菜单；删除继续使用二次确认，避免误删。

### 报表
- 周 / 月 / 季度 / 年均按各自真实时间范围统计，不再统一依赖当前月份。
- 左右切换到历史或未来周期后，会显示对应的“回到本周 / 本月 / 本季度 / 本年”快捷按钮。
- 分类构成和排行榜继续支持整行点击进入明细，并保持较大的触控热区。

### 流畅度
- 主 Tab 从 PageView 动画切换改为 IndexedStack 保活，点击 Tab 后立即进入可滚动状态，避免切换动画期间短暂无响应。
- 各 Tab 页面保持状态与滚动位置，减少重复创建和布局。
- 明细按日期分组改用 Sliver 懒构建，并增加 RepaintBoundary，减少长账单列表的首帧压力。
- 降低大面积毛玻璃和阴影的实时栅格成本，同时保留现有视觉效果。
- Android 端继续请求 120Hz 刷新率；实际帧率仍由荣耀系统刷新率策略、温控和省电模式共同决定。

### 升级说明
v2.2.0 使用与 v2.1.0 相同的长期固定签名，已安装正式 v2.1.0 的设备可以直接覆盖升级并保留本地账本数据。
