## 拾光账本 v2.3.0 · 报表视觉与交互优化

### 明细页
- 点击金额后，当前金额默认处于“覆盖输入”状态；第一次输入数字会直接替换旧金额，无需逐位删除。
- 结余为负数时保留负号，并使用偏红色强调显示，避免误读为正结余。

### Tab 切换
- 保留各页面状态与滚动位置，不重新创建页面。
- 在不阻塞当前页面手势的前提下加入约 145ms 的轻量淡入/缩放过渡，降低 IndexedStack 瞬切的生硬感。

### 报表页
- 参考暖金色报表设计稿重构顶部视觉层级、周期导航和数据卡片布局。
- 周 / 月 / 季度 / 年继续支持前后周期切换与“回到本周 / 本月 / 本季度 / 本年”。
- 支出/收入构成改为带间隔的圆角环形图，采用 12 色独立报表色板；类别超过 8 个时自动合并尾部小项，减少撞色和视觉噪声。
- 新增“消费洞察”：最大类别占比、周末消费/入账占比、最大单笔记录。
- 新增“收支日历热力”，按自然月观察每天支出强度。
- 排行榜增加占比、笔数和更清晰的视觉进度条，整行保持大触控区域。
- 趋势节点仍可点击查看该时间节点对应的账单明细。

### 构建与升级
- 版本号：`2.3.0+5`
- ARM64 Release APK。
- 继续使用自 v2.1.0 起的固定长期签名，已安装正式 v2.1.0 / v2.2.0 的设备可直接覆盖升级并保留本地账本数据。
