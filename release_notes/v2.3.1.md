## 拾光账本 v2.3.1 · Tab 重叠修复

这是 v2.3.0 的紧急修复版本。

### 修复
- 修复在“明细 / 报表 / 预算 / 我的”之间切换时，旧页面可能停留在屏幕上并与当前页面发生叠加的问题。
- 根因是 v2.3.0 的页面淡入淡出动画与 `TickerMode` 组合方式不正确：页面切出后动画 ticker 被立即暂停，导致旧页面透明度可能被冻结在可见状态。
- 主 Tab 容器改回稳定的 `IndexedStack` 单页绘制方案，同时保留各页面状态、滚动位置和数据状态。
- 非当前页面继续关闭 ticker，避免后台页面动画消耗性能。
- 底部导航本身的轻量图标/文字动画保留，切换响应保持快速。

### 回归验证
- 新增 Tab 切换回归测试，验证主页面始终由同一个 `IndexedStack` 控制，并可正确切换 0 / 1 / 2 / 3 页面索引。

### 构建与升级
- 版本号：`2.3.1+6`
- ARM64 Release APK。
- 继续使用 v2.1.0 起的固定长期签名，可从正式 v2.1.0 / v2.2.0 / v2.3.0 直接覆盖升级并保留本地数据。
