# 拾光账本 v2.4.0

基于 v2.3.1，保留新版报表、金额快捷覆盖输入、负结余显示以及 Tab 单页绘制修复。

- 明细按账单逐行懒加载，同一天大量账单不再一次创建全部组件。
- 缓存排序后的账单及月份查询，账单修改和本地恢复后失效，减少重复排序。
- 首次访问时才创建 Tab 页面，保留滚动位置，并暂停非当前页动画。
- 普通账单变更不再重建应用主题；深浅色主题复用。
- 移除导航栏和公共底栏的实时背景模糊，采用实色表面、轻阴影、细分隔线及更克制的字重。
- 记账页使用 Cupertino 模态转场，防止连续点击重复打开。

版本号 `2.4.0+7`，沿用长期签名和原有存储格式。

验证：发布流水线执行 Flutter 分析、回归测试、ARM64 Release 构建及签名校验。未进行真机帧耗时测量，不宣称固定帧率。建议在高刷设备上对比长列表滚动、切换报表、打开记账页和键盘输入，并验证覆盖安装后的历史账单。
