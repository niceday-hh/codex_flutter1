# 拾光账本 v2.7.0 · 日期资料可更新

- 新增“我的 → 日期资料更新”，日历底部也可进入。支持选择2007年至当前年份下一年，手动检查。
- 自动检查默认关闭；开启后，启动/回到前台时检查今年和下一年，每个年份24小时最多尝试一次，不常驻后台。
- 放假调休通过 NateScarlet/holiday-cn 第三方结构化资料读取，展示国务院原公告链接；节气直接读取香港天文台年度历表。
- 假期和节气分别校验与缓存。来源无资料、网络失败、格式异常、保存失败分别说明；失败不会清空已取得的资料，不将404解释为官方未公布。
- 更新后日历即时刷新，已缓存年份离线可用；未获得假期的年份不推断调休工作日。
- 日期资料使用独立本机缓存，不改账单格式，不上传账单。新增Android联网权限，仅访问公开日期数据。
- 版本2.7.0+10，沿用长期签名。

验证涵盖真实2026假期与2027节气资料解析、错年/重复日期/不完整节气拒绝、部分成功、离线缓存恢复、更新失败保留、频率限制、跨年检查及保存失败提示。
