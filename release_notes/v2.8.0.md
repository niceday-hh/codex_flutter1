# 拾光账本 v2.8.0

- 报表增加「统计 / 日历」子页，共用周、月、季度、年范围与收入/支出筛选。
- 季度三个月、年度十二个月热力日历，所选范围统一色阶；点击月份或日期进入月度详情，保留节假日、节气与调休说明。隐藏金额时同步隐藏热力。
- 排行榜分类明细支持金额从高到低/从低到高、时间最新/最早优先；对完整明细排序，保留分类内占比。
- 记一笔与首页修改备注共用新弹窗：常用词云、最近、全部，分类筛选、搜索、手动输入与清空；历史备注不受快捷备注数量限制。
- 继续使用固定 Android 签名，versionCode 11，可覆盖长期签名版本安装。

构建门禁：Flutter 静态分析、自动化测试、ARM64 Release 构建与固定签名校验。未完成实体手机流畅度实测。
