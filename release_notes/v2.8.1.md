# 拾光账本 v2.8.1

本次仅优化性能，保留 v2.8.0 的全部界面和交互，包括备注词云/最近/全部、搜索、分类筛选、手动输入/清空、收支排序以及周/月/季度/年日历。

- 历史备注和快捷备注使用缓存；选择或填写备注不再反复扫描、排序完整账本。
- 数字输入复用分类网格和键盘，保留原有动画、触感及布局。
- 已访问的后台标签页延后刷新，切回时显示最新账本并保留页面状态和滚动位置。
- 大账本启动解析、保存编码移至后台 isolate，Android 读取和写入存储使用有序后台线程。
- 合并连续保存请求并保持写入顺序；启动读取期间的新记录和设置不会被旧数据覆盖。
- 首页按日分组复用缓存，设置变化不会反复清空账本缓存。

验证：完整 Flutter 静态分析和回归测试、ARM64 Release 构建与固定签名校验。新增大账本启动、保存顺序、备注输入工作量和页面重建回归用例。未做实体手机帧率实测，不声称具体帧率提升。

版本：2.8.1+12；继续使用固定签名，可覆盖长期签名版本安装。
