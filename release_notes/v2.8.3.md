# 拾光账本 v2.8.3

- 记一笔的每个金额最多输入两位小数，左侧计算式与实际保存精度一致，避免退格时先删除看不到的小数位。
- 删除最后一位小数时同步移除小数点，例如 `12.34 → 12.3 → 12 → 1`；末尾仅有小数点时，退格同时删除上一位数字。
- 右侧金额保留单笔输入的末尾零，例如 `12.30`，输入和删除都有可见反馈。数值仍在按键接触时立即更新，保留轻量金额动效及减少动效支持。
- 加减计算使用整数分累计，避免浮点精度残差；保留九位数字上限和现有计算、备注、分类、日期及保存功能。
- 全新原创矢量应用图标：暖橙账本、奶油白书页、墨绿书签与拾光星芒。覆盖普通桌面、自适应圆形/圆角图标及 Android 13 主题图标。

验证：新增小数位限制、跨小数点连续退格、末尾零、加减运算、按下即更新及保存精度回归；发布流程执行完整静态分析、Flutter 测试、ARM64 Release 构建和固定签名校验。未进行实体手机帧率/触摸延迟实测。

版本 2.8.3+14，可覆盖安装长期签名版本。
