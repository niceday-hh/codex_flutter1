# 拾光账本 v3.0.0 · 离线语音记账

- 长按首页底部“＋”，选择“语音记账”。暖橙、奶油白和绿色声波弹窗与现有界面一致。
- 内置 Paraformer-zh 220M INT8 普通话离线模型，安装后无需下载或联网识别。首次打开语音时后台准备模型；录音和识别不阻塞页面主线程。
- 按住说话，松手识别并拆分金额、支出/收入、分类、备注和日期。展示识别原文和可编辑草稿，只有点击“确认记账”后才保存；支持再次录音、下拉关闭和关闭按钮。
- 本地规则支持阿拉伯数字、中文数字、块/元/毛/角/分、口语小数、昨天/前天/明确日期、总额及更正表达。餐饮、日用、家居、住房、交通、工资、退款等按具体用途优先分类。
- 未识别金额、多笔金额无明确总额、用途不明确等会提示核对，不自动合并多笔；可以手动修正金额、收支、分类、备注和日期。
- 录音最长 30 秒；关闭弹窗或应用进入后台会取消录音，临时语音文件处理后清除。录音不上传服务器。模型关闭后释放推理资源，保留此前所有记账、备注、报表、日历、洞察和数据功能。

模型文件约 227 MB，安装包会明显增大；安装后首次使用会提取模型至应用私有目录。模型作者 FunASR / Alibaba，ONNX 转换 sherpa-onnx / Fangjun Kuang，许可随应用提供。

验证：完整 Flutter 静态分析和功能测试；本地拆分、权限等待/提前松手、取消、再次录音、确认保存与滑动关闭回归；固定模型 SHA256 校验、真实普通话音频推理、APK 内模型和 ARM64 运行库检查、固定签名验证。尚未在荣耀 100 上实测延迟、内存或与 Whisper 对比准确率。
