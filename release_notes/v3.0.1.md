# 拾光账本 v3.0.1 · 安装签名兼容性修复

- 针对荣耀安装器提示“安装包未包含任何证书”，将发布 APK 显式签为 V1 + V2 + V3，不再只依赖构建工具默认签名方案。
- 继续使用原有长期签名证书和包名，版本号递增至 3.0.1+16，可覆盖安装，不需卸载旧版或清除账目。
- 新增独立的传统 JAR/V1 证书读取校验：逐个读取包括语音模型在内的 APK 条目，检查签名和固定证书指纹；同时校验 V2/V3 签名与 APK 对齐。
- 发布后从 GitHub 回下载安装包，对比本地文件 SHA256，再验证签名，提供对应 SHA256 校验文件。
- 保留 v3.0.0 的 Paraformer-zh 离线语音输入、字段拆分、核对修改和全部已有功能。

说明：已核对 v3.0.0 的构建日志及 GitHub 文件摘要，上一版具有有效 V2 签名，并非完全未签名。默认验签可能跳过 V1，不能仅凭默认输出判断是否包含传统证书。本次补齐签名兼容性；尚未在用户的荣耀 100 上验证具体安装器行为。
