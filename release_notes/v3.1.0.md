# 拾光账本 v3.1.0 · 更懂你的离线语音记账

- 语音分类接入完整历史备注，按收支类型隔离检索，结合备注在各分类中的次数和最近使用日期，显示推荐依据与候选分类。
- 明确口述的分类优先；本次具体用途参与判断，例如历史上的“盒马”属于餐饮，本次“盒马买纸巾”仍可推荐日用。历史有歧义时提示选择，不自动写入。
- 显式备注也参与用途分析，支持“花28元，备注牛肉面”和“备注牛肉面，花28元”。备注中的数量不混入金额提取。
- 确认页支持修改识别原文并重新拆分，保留手动修正的金额、分类、备注、日期和收支类型；再次录音会清空本次修正。
- 语音草稿复用现有完整备注选择器；补充金额、修改分类或日期后，相应已解决提示同步消失。
- 语音模型仅在用户打开语音输入时加载。连续使用可复用45秒，闲置超时、进入后台、打开手动记账或空闲时内存紧张会释放；回到前台不会自动重新加载。关闭弹窗立即停止录音。
- 增加模型准备失败的清理重试和识别超时，保留离线识别、确认后入账及原有手动交互。
- 延续原包名和长期签名证书，V1/V2/V3签名与下载完整性校验，可覆盖安装。

说明：分类属于本地规则与个人历史推荐，支持用户核对修改；没有上传语音或账目，也没有运行后台语音服务。实际手机响应时间与内存占用仍需设备验证。
