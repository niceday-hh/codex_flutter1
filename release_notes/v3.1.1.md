# 拾光账本 v3.1.1 · 前台语音预加载

- 首次打开App时，在首帧显示后异步准备离线语音模型；从其他应用切回拾光账本时自动重新准备。
- 模型在前台期间持续保留，关闭语音弹窗、切换报表等页面或使用手动记账不再回收，不再受45秒闲置限制。
- 真正切到后台或关闭App时释放模型；快速往返应用时，串行清理旧模型，合并重复预加载请求，忽略过期准备结果。
- 预加载只准备识别模型，录音器与麦克风权限检查推迟到按住说话时。关闭语音弹窗仍会停止录音。
- 系统内存紧张时允许回收空闲模型，不会立即循环重载；下次使用语音或回到前台时恢复准备。
- 保留原有语音识别、历史备注辅助分类、原文修改重拆及全部手动记账功能，沿用原长期证书支持覆盖升级。

说明：预加载尚未完成时，语音页仍会等待准备完成；实际加载耗时与手机性能有关。
