# 拾光账本 v3.1.2 · 语音日期与拆分准确性优化

- 支持中文、数字及混合年月日，兼容空格、YYYY-MM-DD 和 YYYY/MM/DD；新增去年、上个月十五号、三天前、上星期一等常见补记表达，正确处理跨月、跨年及闰日。
- 明确年月日不再被星期覆盖；日期冲突、未来日期和无法确定的日期会提示核对。支持“不是昨天，是前天”和“改成”等日期更正。
- 区分记账日期与商品、账期日期，例如“今天买了明天的电影票”“交了上个月的电费”，保留相关备注。
- 金额识别排除时长、数量、折扣和时刻，减少“30分钟”被误当成零钱的问题，保留元角分与口语小数。
- 区分收到物品和收到钱；收付款同时出现时提示核对。否定、更正后的用途、类型和金额优先参与拆分。
- 保留现有界面、历史备注辅助分类、手动修正及前台语音模型预加载；没有新增模型或联网依赖。

说明：仍为本地确定性规则，不是通用语义模型。模糊日期、复杂表达和多笔账需在确认页核对；尚不自动拆成多条记录。沿用长期签名，可覆盖升级。
