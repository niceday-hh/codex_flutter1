# 拾光账本 v3.1.3 · 上滑记账入口

- 底部＋新增连续上滑选择：触住上滑立即展开左侧「手动记账」与右侧「语音记账」，滑到目标高亮后松手进入，无需等待长按或二次点击。
- 沿用暖黄、薄荷绿和圆形入口，增加轻盈展开、选中放大与轻触反馈；轻点＋仍可直接手动记账。
- 滑回＋、停在两按钮中间或移出目标后松手取消；系统返回、触摸取消、切后台及屏幕尺寸变化不会误开页面。
- 滑选和进入语音页均不自动录音，保留原有按住说话、松开识别、核对后保存流程。
- 覆盖快速滑选、双指干扰、深色模式、大字体、减少动态效果与无障碍操作；选择时不重建首页账单。
- 保留语音日期拆分、历史备注辅助分类、前台模型预加载及全部原有记账功能，沿用长期签名支持覆盖升级。
